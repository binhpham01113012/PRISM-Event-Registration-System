# PRISM – Online Event Registration System

PRISM is a database-backed online event registration system developed as a
four-person group project. The application was designed to manage users,
events, registrations, and administrative functions through a centralized
web interface.

## My Role

My primary responsibility was developing the front-end interface and helping
design the database structure. I also collaborated with three other team
members throughout the development and testing process.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- Database Design

## Key Features

- User registration and login
- Event/class registration
- Role-based functionality
- Administrative dashboard
- Registration management
- Calendar
- Attendance tracking
- Waitlists and cancellations
- User profiles

## About the Project

This project gave me hands-on experience with full-stack web development,
database design, troubleshooting, and collaborative software development.
